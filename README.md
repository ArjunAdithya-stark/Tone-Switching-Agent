# Tone Switching Agent

AI-based system that converts text into different tones (formal, informal, polite, professional) while preserving meaning.

---

## Description

The Tone Switching Agent is a lightweight NLP-based system designed to transform user input text into different tones such as formal, informal, polite, and professional.

In modern communication, users often struggle to adjust tone based on context. This project provides an automated and user-friendly solution to improve communication quality.

---

## Features

- Convert text into multiple tones  
- Formal, Informal, Polite, Professional  
- Preserves original meaning  
- Fast and lightweight  
- Easy to use  

---

## Tech Stack

- Python  
- Natural Language Processing (Rule-based)  
- Optional AI Integration  

---

## Setup

1. Clone the repository:
   git clone https://github.com/ArjunAdithya-stark/Tone-Switching-Agent.git

2. Navigate to the project folder:
   cd Tone-Switching-Agent

3. Install dependencies:
   pip install -r requirements.txt

---

## Usage

1. Run the program:
   python main.py

2. Enter your text input

3. Choose the desired tone:
   - Formal
   - Informal
   - Polite
   - Professional

4. View the transformed output

---

## Example

Input: Send me the file  
Tone: Polite  
Output: Kindly send me the file
